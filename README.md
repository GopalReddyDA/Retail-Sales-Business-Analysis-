# Retail Sales Analysis using SQL
[!Retail Sales Logo](https://github.com/GopalReddyDA/Retail-Sales-Business-Analysis-/blob/main/Logo.png)

## Project Overview

This project analyzes retail sales data using SQL to answer real-world business questions. It demonstrates data cleaning, data exploration, and business analysis using SQL queries.

## Objectives

* Clean the dataset by removing missing values.
* Explore the sales data.
* Answer business questions using SQL.
* Generate insights to support business decisions.

## Dataset

The dataset contains retail transaction details, including:

* Transaction ID
* Sale Date
* Sale Time
* Customer ID
* Gender
* Age
* Product Category
* Quantity
* Price Per Unit
* COGS
* Total Sale

* Date Functions

## Business Questions Solved

1. Retrieve sales made on a specific date.
2. Find Clothing transactions with quantity greater than a given value.
3. Calculate total sales for each category.
4. Find the average customer age for the Beauty category.
5. Retrieve transactions where total sales exceed a specified amount.
6. Count transactions by gender and category.
7. Identify the best-selling month in each year based on average sales.
8. Find the top 5 customers by total sales.
9. Count unique customers for each category.
10. Classify orders into Morning, Afternoon, and Evening shifts.
